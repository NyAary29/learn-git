# 🚀 Git Notes — Guide pratique

## 🖥️ Aperçu : https://nyaary29.github.io/learn-git/

## 📖 Description
Ce dépôt contient une **documentation personnelle et interactive des commandes Git**, construite comme un mémo rapide pour un usage quotidien.

L’objectif est de centraliser :
- les commandes essentielles
- les concepts clés
- les bonnes pratiques
- des exemples concrets d’utilisation

---

## 🎯 Objectifs
- Comprendre rapidement les commandes Git les plus utilisées
- Disposer d’un **référentiel clair et accessible**
- Faciliter la révision et la pratique au quotidien

---

## 📚 Contenu
- 🔎 Historique (`git log`, filtres…)
- 🔄 Annulation et correction (`restore`, `revert`, `amend`)
- 🌿 Gestion des branches
- ⚡ Commandes avancées (`rebase`, `stash`, `bisect`)
- 🔍 Recherche dans un dépôt (`grep`, `blame`, `log -L`)
- 🧠 Alias Git pour gagner du temps
