Consulter l'historique
git log
Affiche la liste de tous les commits du plus récent au plus ancien.
git log --oneline
Format compact — l'option la plus utilisée au quotidien. Recommandé.
git log --oneline --graph --all --decorate
Visualise les branches et les merges directement dans le terminal.
git log --pretty=format:"%h %an %ar %s"
Contrôle total sur l'affichage avec des placeholders personnalisés.
%HSHA complet
%hSHA abrégé
%annom auteur
%aeemail auteur
%ardate relative
%aidate ISO
%smessage (1ère ligne)
%dbranches / tags
git log --stat --oneline
Affiche les fichiers modifiés avec le nombre de lignes ajoutées (+) et supprimées (−).
git log -p -1
Affiche les modifications complètes (diff) du dernier commit.
Filtrer l'historique
git log -N
Limite le nombre de commits affichés.
git log -5Les 5 derniers commits
git log --oneline -10Les 10 derniers en format compact
git log --author="Name"
Filtre les commits par auteur.
git log --since="date" --until="date"
Filtre les commits par plage de dates.
--since="2026-01-01"Depuis une date précise
--until="2026-12-31"Jusqu'à une date précise
--since="2 weeks ago"Les 2 dernières semaines
git log --grep="message"
Filtre par mot-clé dans le message de commit.
git log -S "function_name"
Filtre par contenu modifié — trouve les commits qui ont ajouté ou supprimé une chaîne de caractères dans le code.
git show <commit>
Inspecte le contenu détaillé d'un commit spécifique.
Annuler des modifications
git restore --staged <fichier>
Retire un fichier du staging sans supprimer ses modifications.
git restore --staged .Retire tous les fichiers du staging
git restore <fichier>
Annule les modifications non-stagées d'un fichier. Irréversible.
git restore --source=<commit> <fichier>
Restaure un fichier dans l'état d'un commit précis.
Corriger le dernier commit
git commit --amend -m "message corrigé"
Modifie le message du dernier commit. Ne pas utiliser sur des commits déjà poussés.
git commit --amend --no-edit
Ajoute des fichiers au dernier commit sans changer son message.
Inverser un commit publié
git revert <commit>
Crée un nouveau commit qui annule les changements d'un commit précédent. Sûr pour les branches partagées.
git revert --no-edit <commit>Revert sans ouvrir l'éditeur
git revert --no-edit A..BInverse une série de commits
Contrairement à reset, revert conserve l'historique et peut être poussé sur une branche partagée sans problème.
Alias Git
git config --global alias.xx "commande"
Crée un alias global. Remplacer xx par le nom souhaité.
Alias les plus courants
st= status
co= checkout
sw= switch
br= branch
ci= commit
ca= commit --amend --no-edit
cm= commit -m
lg= log --oneline --graph --all --decorate
ll= log --oneline -15
last= log -1 HEAD --stat
df= diff
ds= diff --staged
ss= stash
sp= stash pop
git config --global --get-regexp alias
Liste tous les alias configurés globalement.
git config --global --unset alias.st
Supprime un alias spécifique.
Branches
git branch <nom>
Crée une nouvelle branche sans basculer dessus.
git switch -c <nom>
Crée une branche et bascule dessus en une seule commande.
git branch [options]
git branchBranches locales uniquement
git branch -aBranches locales + distantes
git branch -vBranches avec leur dernier commit
git branch --mergedBranches déjà fusionnées dans HEAD
git branch --no-mergedBranches non encore fusionnées
git switch -
Revient à la branche précédente (comme cd - dans le terminal).
git branch -d <nom>
Supprime une branche déjà fusionnée. Utilisez -D pour forcer la suppression même sans fusion.
git branch -m <nouveau-nom>
Renomme la branche courante.
git branch -m <ancien> <nouveau>Renomme une branche spécifique
Branches distantes et tracking
git fetch origin
Récupère les changements distants sans les fusionner dans la branche locale.
git branch -vv
Voir toutes les relations de tracking (avance / retard par rapport à la branche distante).
git switch --track origin/<branche>Créer et suivre une branche distante
git branch -u origin/<branche>Définir le tracking sur une branche existante
git push -u origin <branche>
Premier push — crée la branche distante et configure le tracking.
git push --all originPousse toutes les branches
git push origin --delete <branche>Supprime une branche distante
Cherry-pick
git cherry-pick <commit>
Copie un commit précis sur la branche actuelle. Utile pour récupérer un correctif sans fusionner toute une branche.
git cherry-pick A..DDu commit A (exclu) au commit D (inclus)
git cherry-pick A^..DDu commit A (inclus) au commit D (inclus)
Outils avancés
git add -p
Commiter seulement une partie des modifications — choisir les hunks à inclure de façon interactive.
git stash
Met de côté les modifications en cours pour pouvoir changer de branche. Récupérer avec git stash pop.
git rebase -i HEAD~N
Nettoyer et réorganiser les commits avant de pousser. Permet de squasher, renommer, réordonner.
git bisect
Recherche par dichotomie binaire le commit qui a introduit un bug.
git merge --abort
Annule un merge en cours en cas de conflits non résolus.
Recherche dans le dépôt
git grep "TODO"
Cherche une chaîne de caractères dans tout le dépôt. Plus rapide que grep classique car il ignore les fichiers non-trackés.
-nAffiche les numéros de ligne
-cCompte les occurrences par fichier
-lListe uniquement les fichiers concernés
-iInsensible à la casse
-wMot entier uniquement
-pAffiche la fonction englobante
git grep -l -e "calculate" --and -e "price"
Fichiers contenant "calculate" ET "price".
git grep -e "error" --or -e "warning"Lignes contenant "error" OU "warning"
git grep "mot" <branche>Chercher dans une autre branche
git blame -L 42,50 src/app.py
Affiche qui a écrit chaque ligne dans une plage donnée du fichier.
git log -L :calculate_price:src/app.py
Voir l'évolution complète d'une fonction dans l'historique.
Workflow de débogage
Étape 1 — git grep -n "calculate_price" → trouver où la fonction est utilisée
Étape 2 — git log -S "calculate_price" → quand a-t-elle été modifiée ?
Étape 3 — git log -L :calculate_price:src/app.py → voir l'évolution complète
Étape 4 — git blame -L 42,50 src/app.py → qui a écrit cette ligne ?
